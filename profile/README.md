# CodeAgent Mobile

**[Remix](https://www.codeagent-mobile.com/remix)** — apps you can use, change and ship by telling it what you want in one sentence.

- **Explore** a feed where every post is a working app. Use any of them in one tap, no account needed.
- **Make your own version** of any app: say what you'd change, by text or voice, and your copy is live with its own link in about a minute.
- **Build a new app** from a one-sentence idea. Web apps open in any browser; phone apps are real native iOS and Android apps.
- **Publish** to Google Play and the App Store from your own developer accounts.
- **Test apps before launch** by joining an app's internal test in one tap, and earn a Tester badge you can share.

Not sure what to build? **[150 app ideas](https://www.codeagent-mobile.com/app-ideas)** — every one is a live app with the prompt that builds it.

## Advanced console — for developers

Run the AI coding agents you already use (Claude Code, Codex, Cursor, Gemini and more) through the whole delivery cycle, from your phone: start a session from a Jira, Linear or Azure DevOps ticket, follow the agent live and approve its steps, preview the running app, review and merge the pull request, and the agent closes the loop on the ticket. The agent runs on your laptop, in a GitHub Codespace or on your own server.

## Open source

- [`codeagent-mobile-clients`](https://github.com/edgar-durand/codeagent-mobile-clients) — `codeam-cli`, the VS Code / Cursor / Windsurf extension and the JetBrains plugin.
- [`codeagent-mobile-ide`](https://github.com/edgar-durand/codeagent-mobile-ide) — `@codeam/ide`, the IDE component library used by the apps.
